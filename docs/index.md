## Project Overview

Resume-builder-v1 produces ATS-optimized, tagged PDF resumes from job descriptions or structured JSON. A single pipeline in `packages/core` is consumed by an Express API, a Vite SPA, and a CLI. See [Project Overview](./project-overview.md).

## Project Structure

| Part | Type    | Location   | Stack / Entry |
|------|---------|------------|----------------|
| **API**  | backend | `apps/api` | Express; `index.ts` |
| **Web**  | web     | `apps/web` | Vite, @repo/ui |
| **CLI**  | cli     | `apps/cli` | Node; `bin/run.js` |

## Quick Reference

- **API:** Express, `/api/run-pipeline`, `/api/scrape-jd`; CORS via `FRONTEND_ORIGIN`.
- **Web:** Vite SPA, `VITE_API_URL` → API.
- **CLI:** Direct `runPipeline()` from `@repo/core`.

## Getting Started

1. **Prerequisites:** Node 18+, pnpm, optional `ANTHROPIC_API_KEY`.
2. **Install:** `pnpm install`
3. **API:** Copy `apps/api/.env.example` → `apps/api/.env`, then `pnpm --filter api dev`
4. **Web:** `pnpm --filter web dev`
5. **CLI:** `pnpm --filter cli build` then `node apps/cli/bin/run.js --help`
6. **Verify:** `bash scripts/verify.sh`
